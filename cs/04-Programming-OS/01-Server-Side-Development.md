# 01. 서버 프로그램 구현

## SECTION 094. 서버 개발

### 1. 서버 개발

-   **서버 개발** → 웹 애플리케이션 로직 구현 → **웹 애플리케이션 서버(WAS) 탑재**
-   **WAS 서버 프로그램** → 웹 서버 요청 처리 → 결과 반환
-   언어 → `Java / JavaScript / Python / PHP / Ruby`

### 2. 서버 개발 프레임워크

-   프레임워크 → 서버 개발을 쉽게 지원하는 **클래스·인터페이스**
-   기본 패턴 → **MVC (Model - View - Controller)**

### 3. 서버 프로그램 구현

-   구현 → **모듈 + 공통 모듈 개발 → 통합**
-   모듈 → **기능적 독립성** 중요
-   독립성 ↑ → **결합도 ↓ / 응집도 ↑ / 모듈 크기 ↓**
-   **공통 모듈** → 재사용 가능
    -   예: 계산식, 사용자 인증

## SECTION 096. 배치 프로그램

### 1. 배치 프로그램

-   **Batch Program** → 사용자와 상호작용 없이 → 정해진 순서대로 **일괄
    처리**

#### 배치 종류

종류                 키워드
  -------------------- ------------------------------
**정기 배치**        정해진 기간마다 (`일/주/월`)
**이벤트성 배치**    특정 **조건 충족** 시
**On-Demand 배치**   **사용자 요청** 시

#### 필수 요소

-   **대용량 데이터** → 대량 처리 가능
-   **자동화** → 사용자 개입 없이 수행
-   **견고성** → 잘못된·중복 데이터에도 중단 X
-   **안정성/신뢰성** → 오류 위치·시간 추적
-   **성능** → 다른 프로그램 방해 X + 지정 시간 내 완료


### 2. 배치 스케줄러

-   **Batch Scheduler** → 설정된 주기에 맞춰 자동 수행
-   **Job Scheduler** → Job을 원하는 시간에 처리
-   예 → `Spring Batch / Quartz`

------------------------------------------------------------------------

## Spring Batch

-   Spring 기반 **오픈 소스 프레임워크**
-   DB·파일 데이터 교환 컴포넌트 제공
-   로그 / 추적 / 트랜잭션 / 통계 / 작업 재시작 등 지원

### 주요 구성 요소

구성 요소            역할
  -------------------- ---------------------
**Job**              수행할 작업 정의
**Job Launcher**     실행 인터페이스
**Step**             Job 처리 제어 정보
**Job Repository**   작업 실행 정보 저장

------------------------------------------------------------------------

## Quartz

-   일괄 처리 기능을 제공하는 **오픈 소스 라이브러리**
-   수행할 **작업과 수행 시간**을 관리하는 요소를 분리 → 유연성 ↑

### 주요 구성 요소

구성 요소       역할
  --------------- ----------------------
**Scheduler**   실행 환경 관리
**Job**         수행할 작업 정의
**JobDetail**   Job 상세 정보
**Trigger**     Job 실행 스케줄 정의
