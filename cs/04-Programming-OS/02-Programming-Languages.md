## SECTION 098. 변수

### 1. 변수
-   **변수** - 값을 저장하는 공간
-   종류 - 정수 / 실수 / 문자 / 포인터 등

### 2. 변수명 규칙
-   사용 가능 → **영문자 / 숫자 / `_`**
-   첫 글자 → **영문자 또는 `_`** / 숫자 ❌
-   공백·특수문자 ❌
-   대소문자 구분
-   예약어 ❌
-   선언 끝 → `;`
-   **헝가리안 표기법** → 변수명에 **데이터 타입 명시**

### 3. 기억 클래스
종류|핵심
---|---
**자동(auto)**|블록 내부 / 실행 중 존재 / 종료 시 소멸 / 초기화 X → **쓰레기값**
**외부(extern)**|함수 밖 / 종료 후에도 유지 / 초기화 X → **0**
**정적(static)**|종료 후에도 유지 / 초기화 1회 / 초기화 X → **0**
**레지스터(register)**|PU 레지스터 저장 / 빠름 / 종료 시 소멸 / `&` 사용 X

> ⭐ `auto = 쓰레기값`\
> ⭐ `extern·static = 초기화 안 하면 0`\
> ⭐ `register = CPU / 주소 연산자(&) 불가`

> #### 가비지 컬렉션
> -   **Garbage Collection** → 사용하지 않는 변수가 차지한 메모리 해제
> -   수행 모듈 → **Garbage Collector**

### 4. 변수 선언
``` c
자료형 변수명 = 값;
int a = 5;
```
-   `char aa = 'A'` - 문자 A / ASCII 값으로 저장
-   `'1'` - 숫자가 아니라 **문자**
-   실수 기본형 - **double**
-   `float fl = 24.56f;` - float는 `f`
-   `1.23e-2` - `1.23 × 10^-2 = 0.0123`
-   문자열 - `char a[] = "hello";`

## SECTION 099. 연산자

### 1. 산술 연산자
연산자|의미
---|---
`+`|덧셈
`-`|뺄셈
`*`|곱셈
`/`|나눗셈
`%` |나머지

#### 증감 연산자
-   **전치** `++a` → **먼저 증감 → 연산**
-   **후치** `a++` → **먼저 연산 → 나중 증감**

### 2. 관계 연산자
-   결과 - `True / False`
-   거짓 = `0`, 참 = `1`
-   **0 이외의 숫자 → 참**

연산자|의미
---|---
`==`|같다
`!=`|다르다
`>`, `>=`|크다, 크거나 같다
`<`, `<=`|작다, 작거나 같다

### 3. 비트 연산자
연산자|의미
---|---
`&`|AND - 둘 다 1이면 1
`^`|XOR - 같으면 0, 다르면 1
`\|`|OR - 하나라도 1이면 1
`~`|NOT
`<<`|비트를 왼쪽으로 이동
`>>`|비트를 오른쪽으로 이동

### 4. 논리 연산자
 연산자 | 의미          
--------|---
 `!`    | NOT           
 `&&`   | AND - 둘 다 같으면 참(1) 
 `\|\|` | OR - 하나라도 참(1)이면 참(1)

### 5. 대입 연산자
연산자|의미
---|---
`a += 1` | `a = a + 1`
`a -= 1` | `a = a - 1`
`a *= 1` | `a = a * 1`
`a /= 1` | `a = a / 1`
`a %= 1` | `a = a % 1`
`a <<= 1` | `a = a << 1`
`a >>= 1` | `a = a >> 1`

### 6. 조건 연산자
``` c
조건 ? 수식1 : 수식2;
```

-   참 → **수식1**
-   거짓 → **수식2**

### 7. 기타 연산자
| 연산자 | 핵심 |
|---|---|
| `sizeof` | **자료형의 크기**를 표시 |
| `,` | 여러 수식·변수를 한 줄에 작성 / **왼쪽 → 오른쪽** 순서로 수행 |
| `(자료형)` | **형 변환(cast)** 연산자 |

```c
a = (int)1.3 + (int)1.4;
// 1 + 1 = 2
```

> ⭐ `sizeof = 크기`  
> ⭐ `, = 순서대로 실행`  
> ⭐ `(자료형) = 형 변환`

### 8. 연산자 우선순위
| 순위 | 연산자 종류         | 연산자                                      |
|-----:|---------------------|---------------------------------------------|
|    1 | **단항**            | `!` `~` `++` `--` `sizeof`                  |
|    2 | **산술(곱·나눗셈)** | `*` `/` `%`                                 |
|    3 | **산술(덧·뺄셈)**   | `+` `-`                                     |
|    4 | **시프트**          | `<<` `>>`                                   |
|    5 | **관계**            | `<` `<=` `>=` `>`                           |
|    6 | **비교(동등)**      | `==` `!=`                                   |
|    7 | **비트**            | AND `&` - XOR `^` - OR `\|`                 |
|    8 | **논리**            | AND`&&` - OR `\|\|`                         |
|    9 | **조건**            | `? :`                                       |
|   10 | **대입**            | `=` `+=` `-=` `*=` `/=` `%=` `<<=` `>>=` 등 |
|   11 | **순서(콤마)**      | `,`                                         |

> ⭐ 단항 → 산술(`*`,`/`,`%` -`+`,`-`)→ 시프트 → 관계 → 비교(동등) → 비트(`&`-`^`-`|`) → 논리(`&&`-`||`) → 조건 → 대입 → 콤마

#### 결합 규칙
- 같은 우선순위의 연산자가 여러 개면 **결합 규칙**에 따라 계산
    - `←` - **오른쪽부터 계산**
    - `→` - **왼쪽부터 계산**
- **단항 연산자 / 대입 연산자** - `←`
- 대부분의 이항 연산자 / 콤마 - `→`

> ⭐ **우선순위 먼저 → 같으면 결합 규칙 확인**

## SECTION 101. 제어문

### 1. 제어문
- 프로그램 명령의 **실행 순서를 변경**
- 종류 → `if`, `switch`, `goto`, 반복문 등

### 2. if문
#### 단순 if
```c
if (조건) {
    실행문;
}
```
- 조건 참 → 실행
- 조건 거짓 → 실행하지 않음

#### if ~ else
```c
if (조건) {
    실행문1;
} else {
    실행문2;
}
```
- 참 → 실행문1
- 거짓 → 실행문2

#### 다중 if
```c
if (조건1) {
    ...
} else if (조건2) {
    ...
} else {
    ...
}
```
- 여러 조건을 **순서대로 판단**

#### 중첩 if
- `if`문 안에 또 다른 `if`문 사용 가능

> ⭐ `if = 조건에 따라 실행 경로 선택`

### 3. switch문
- 조건값에 따라 여러 분기 중 하나 선택
    ```c
    switch (수식) {
        case 값1:
            실행문;
            break;
        case 값2:
            실행문;
            break;
        default:
            실행문;
    }
    ```
  - `case` → 비교할 값
  - `break` → 해당 case 종료 후 switch 탈출
  - `default` → 일치하는 case가 없을 때 실행
  - `break`가 없으면 다음 case까지 계속 실행될 수 있음

> ⭐ `case = 값 / break = 탈출 / default = 그 외`

### 4. goto문
- 지정한 **레이블(label)** 위치로 강제 이동
    ```c
    goto 레이블;
    
    레이블:
        실행문;
    ```
    - 이동은 쉽지만 프로그램 이해·유지보수가 어려워져 **거의 사용하지 않음**

## SECTION 102. 반복문

### 1. 반복문의 개요
- 일정한 횟수 또는 조건에 따라 같은 명령을 반복
- 종류 → `for`, `while`, `do ~ while`

### 2. for문
```c
for (초기값; 최종조건; 증감값) {
    실행문;
}
```

#### 실행 순서
`초기값 → 조건 검사 → 실행문 → 증감 → 조건 검사 → ...`

- 초기값 / 조건 / 증감값은 생략 가능
- 조건을 만족하는 동안 반복

> ⭐ `for = 반복 횟수가 비교적 명확할 때`


### 3. while문

```c
while (조건) {
    실행문;
}
```

- **조건 먼저 검사**
- 처음부터 조건이 거짓이면 **한 번도 실행하지 않을 수 있음**

> ⭐ `while = 선검사`


### 4. do ~ while문

```c
do {
    실행문;
} while (조건);
```

- **실행문을 먼저 수행 → 조건 검사**
- 조건과 관계없이 **최소 1회 실행**

> ⭐ `do ~ while = 후검사 / 최소 1회`



### 5. break / continue

- `break` → 반복문 또는 switch **즉시 종료**
- `continue` → 이후 문장 건너뛰고 **다음 반복으로 이동**

> ⭐ `break = 반복 탈출`  
> ⭐ `continue = 이번 회차만 건너뜀`

## SECTION 103. 배열과 문자열

### 1. 배열
- **같은 데이터형**을 여러 개 저장
- 하나의 배열 이름으로 여러 기억장소 사용
- 개별 요소 위치 → **첨자(index)**
- C언어 배열 첨자 → **0부터 시작**
- 배열 이름만 사용 → **첫 번째 요소의 주소**
- C언어 배열 → **행 우선**으로 저장

```c
int a[5];
```

→ `a[0] ~ a[4]`

> ⭐ `배열 = 같은 자료형 / 인덱스 0부터`

### 2. 1차원 배열
```c
자료형 배열명[개수];
```
- 한 줄 형태로 데이터 저장
- 배열 원소 → `배열명[첨자]`

### 3. 2차원 배열
```c
자료형 배열명[행][열];
```
- 행과 열로 구성
- 원소 접근 → `배열명[행][열]`

> ⭐ 2차원 배열 = `행 × 열`

### 4. 배열 초기화
```c
int a[4] = {10, 20, 30, 40};
```
- 선언과 함께 초기값 지정 가능
- 배열 크기보다 초기값 수가 적으면 **나머지 요소는 0**

> ⭐ `초기값 부족 → 남는 요소 = 0`

### 5. 배열 형태의 문자열
- C언어에는 별도의 문자열 자료형이 없으므로 **문자 배열**로 처리
- 문자열 끝 → **널 문자 `\0` 자동 삽입**
- 배열 크기는 `\0`까지 고려
```c
char a[5] = "love";
```
→ `l / o / v / e / \0`

> ⭐ `"love" = 4글자지만 배열은 5칸`

## SECTION 104. 포인터

### 1. 포인터와 포인터 변수
- **포인터** → 변수의 주소
- **포인터 변수** → 주소를 저장하는 변수
```c
int *p;
```

#### 핵심 연산자
- `&변수` → 변수의 **주소**
- `*포인터` → 포인터가 가리키는 **값**
```c
p = &a;
b = *p;
```

> ⭐ `& = 주소를 구함`  
> ⭐ `* = 주소가 가리키는 값을 구함`

### 2. 포인터 특징·용도
- 메모리에 직접 접근 가능
- 연결 자료구조 구성
- 동적 자료구조 지정
- 배열을 함수 인수로 전달
- 문자열 표현
- 큰 배열을 효율적으로 처리

### 3. 포인터와 배열
- 배열 이름 → **배열 첫 번째 요소의 주소**
- 배열 요소는 포인터 연산으로 접근 가능
    ```c
    p = a;
    ```
    - `a[i]`와 포인터를 이용한 접근은 서로 대응 가능

> ⭐ `배열명 ≒ 첫 요소 주소`

## SECTION 105. 구조체

### 1. 구조체 개요
- **서로 다른 자료형**을 하나의 단위로 묶어 관리
- 배열 → 같은 자료형
- 구조체 → 다른 자료형 가능
    ```c
    struct sawon {
        char name[10];
        char jikwi[10];
        int pay;
    };
    ```
  - `struct` → 구조체 정의
  - 구조체 안의 항목 → **멤버(member)**

> ⭐ `배열 = 같은 자료형 / 구조체 = 서로 다른 자료형`

### 2. 구조체 변수 선언
```c
struct sawon ansan, seoul;
```
- 정의한 구조체를 실제로 사용하려면 **구조체 변수 선언**

### 3. 구조체 멤버 지정
#### 일반 구조체 변수
- **`.` 연산자**
    ```c
    ansan.name
    ansan.pay
    ```

#### 구조체 포인터
- **`->` 연산자**
    ```c
    seoul->name
    seoul->pay
    ```
    또는
    ```c
    (*seoul).name
    ```
  
> ⭐ `일반 구조체 = .`  
> ⭐ `구조체 포인터 = ->`

## SECTION 110. 예외 처리

### 1. 예외 처리 개요
- 프로그램 정상 실행을 방해하는 상황 → **예외(Exception)**
- 예외가 발생해도 프로그램이 비정상 종료되지 않도록 처리 → **예외 처리**
- Java 등 객체지향 언어에서 예외 처리 기능 제공

### 2. Java 예외 처리

#### 기본 구조
```java
try {
    예외가 발생할 가능성이 있는 코드
}
catch (예외객체 변수) {
    예외 발생 시 처리 코드
}
finally {
    예외 발생 여부와 관계없이 실행할 코드
}
```
- `try` → 예외 발생 가능 코드
- `catch` → 발생한 예외 처리
- `finally` → 예외 발생 여부와 관계없이 실행
- 하나의 `try`에 여러 `catch` 사용 가능

> ⭐ `try = 시도 / catch = 잡기 / finally = 무조건`

### 3. Java 주요 예외 객체
| 예외 | 발생 상황 |
|---|---|
| `ClassNotFoundException` | 클래스를 찾지 못함 |
| `NoSuchMethodException` | 메소드를 찾지 못함 |
| `FileNotFoundException` | 파일을 찾지 못함 |
| `InterruptedException` | 실행 중 인터럽트 발생 |
| `ArithmeticException` | 0으로 나누기 등 산술 오류 |
| `IllegalArgumentException` | 잘못된 인수 전달 |
| `NumberFormatException` | 문자열을 숫자로 변환할 수 없음 |
| `ArrayIndexOutOfBoundsException` | 배열 인덱스 범위 초과 |
| `NegativeArraySizeException` | 배열 크기를 음수로 지정 |
| `NullPointerException` | null 객체 참조 |
