## 76. Paging vs Segmentation ★★★★★

### Paging

> **고정 크기**

- 프로그램 → Page
- Main Memory → Page Frame
- 내부 단편화 가능
- 외부 단편화 X
- Page Map Table 필요

### Segmentation

> **가변 크기 / 논리적 단위**

- Segment
- Base Address
- Limit
- 외부 단편화 가능
- 공유·보호 유리

**암기:**  
`Paging = 고정·내부`  
`Segmentation = 가변·외부`

## 77. 페이지 교체 알고리즘 ★★★★★

#### OPT
> **미래에 가장 오랫동안 사용되지 않을 Page**

- Page Fault 가장 적은 이상적 알고리즘
- 실제 구현 어려움

#### FIFO
> **가장 먼저 들어온 Page**

- 구현 간단
- **Belady Anomaly**

#### LRU
> **최근 사용 시점이 가장 오래된 Page**

#### LFU
> **사용 횟수가 가장 적은 Page**

#### NUR
> Reference Bit + Modified Bit

교체 순서:
`00 → 01 → 10 → 11`

#### SCR
> Second Chance  
> 오래된 Page라도 최근 사용됐으면 **한 번 더 기회**

## 93. FCFS / SJF / HRN ★★★★★

#### FCFS

> **먼저 온 Process 먼저**

- 비선점
- 공평
- 긴 작업 때문에 짧은 작업 대기 가능

대기 시간:
> Ready에서 기다린 시간

반환 시간:
> 대기 시간 + 실행 시간

#### SJF

> **실행 시간 가장 짧은 Process 먼저**

- 비선점
- 평균 대기 시간 감소
- 긴 작업 → **Starvation**

#### HRN

> SJF의 Starvation 보완

공식:

`우선순위 = (대기 시간 + 서비스 시간) / 서비스 시간`

> 오래 기다릴수록 우선순위 ↑

## 114. TCP vs IP

#### TCP

> **연결형 / 신뢰성**

- 패킷 순서 제어
- 오류 제어
- 흐름 제어
- Stream
- Connection-Oriented

#### IP

> **비연결형 / 주소 지정 / 경로 선택**

- Datagram
- Best Effort

**암기:** `TCP=연결·신뢰 / IP=비연결·주소·경로`
