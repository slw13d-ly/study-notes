---

### 2. 배열(Array)

문제 키워드:
- **같은 자료형**
- **Index(첨자)**
- **크기 고정**
- 정적 자료 구조
- 반복 처리에 적합

→ **배열(Array)**

**핵심:** `같은 자료형 + Index + 크기 고정`

---

### 3. 선형 리스트

#### 연속 리스트(Contiguous List)

키워드:
- 연속된 기억장소
- 기억장소 이용 효율 좋음
- 삽입·삭제 시 **자료 이동 필요**
- 중간 삽입 시 연속 빈 공간 필요

→ **연속 리스트**

#### 연결 리스트(Linked List)

키워드:
- **Node + Pointer(Link)**
- 비연속 기억장소 가능
- 삽입·삭제 쉬움
- 포인터 저장 공간 필요
- 접근 속도 느림

→ **연결 리스트**

**암기:**  
`연속 = 메모리 연속·이동 필요`  
`연결 = Node+Pointer·삽입삭제 쉬움`

---

## 4. 스택(Stack)

> **LIFO = Last In First Out = 후입선출**

- 삽입 → **PUSH**
- 삭제 → **POP**
- 마지막 삽입 위치 → **TOP**
- 맨 아래 → Bottom

#### Overflow / Underflow

- 가득 차서 삽입 불가 → **Overflow**
- 비어서 삭제 불가 → **Underflow**

#### 스택 활용

- 함수 호출 순서
- 인터럽트 처리
- 수식 계산
- 괄호 검사
- 작업 스케줄링

**암기:**  
`Stack = LIFO / Push 넣기 / Pop 빼기`

---

## 5. 큐(Queue)

> **FIFO = First In First Out = 선입선출**

- **Front = 삭제**
- **Rear = 삽입**

**암기:**  
`Queue = FIFO / Front 삭제 / Rear 삽입`

---

## 6. 데크(Deque)

> **양쪽 끝에서 삽입·삭제 가능**

#### 입력 제한 데크
- **Scroll**
- 입력 한쪽
- 출력 양쪽

#### 출력 제한 데크
- **Shelf**
- 입력 양쪽
- 출력 한쪽

**암기:**  
`Scroll = 입력 제한 / Shelf = 출력 제한`

---

## 7. 그래프(Graph)

구성:

> **Vertex(정점) + Edge(간선)**

#### 최대 간선 수

정점이 `n`개일 때:

- 무방향 그래프 → **n(n-1)/2**
- 방향 그래프 → **n(n-1)**

**암기:**  
`무방향 = 반쪽 / 방향 = 두 배`

#### 인접 행렬

- 인접 → **1**
- 비인접 → **0**

---

## 8. 트리(Tree)

> **사이클이 없는 그래프**

- 맨 위 → Root
- 자식 없음 → Terminal / Leaf
- 노드에서 뻗은 가지 수 → Degree
- 트리의 차수 → **노드 차수 중 최댓값**
- 동일 부모 → Sibling
- 최대 레벨 → Depth

---

## 9. 트리 운행법 ★★★

| 운행 | 순서 | 암기 |
|---|---|---|
| Preorder(전위) | Root → Left → Right | **루왼오** |
| Inorder(중위) | Left → Root → Right | **왼루오** |
| Postorder(후위) | Left → Right → Root | **왼오루** |

**핵심:**
- Pre → Root **먼저**
- In → Root **가운데**
- Post → Root **마지막**

---

## 10. 수식 표기법

예: `A + B`

- Prefix → `+AB`
- Infix → `A+B`
- Postfix → `AB+`

**암기:**
- Prefix = 연산자 **앞**
- Infix = 연산자 **중간**
- Postfix = 연산자 **뒤**

---

## 11. 정렬(Sort) ★★★

| 정렬 | 문제 키워드 | 평균 | 최악 |
|---|---|---:|---:|
| Insertion | 앞쪽 정렬 영역에 **삽입** | O(n²) | O(n²) |
| Shell | Insertion 확장 / **간격 h** | O(n^1.5) | O(n²) |
| Selection | 매 회 **최솟값 선택** | O(n²) | O(n²) |
| Bubble | **인접** 자료 비교·교환 | O(n²) | O(n²) |
| Quick | **Pivot / 분할정복** | O(n log n) | O(n²) |
| Heap | **완전 이진 트리** | O(n log n) | O(n log n) |
| Merge | 정렬된 **두 파일 합병** | O(n log n) | O(n log n) |
| Radix | **자릿수 / Bucket / Queue** | O(dn) | O(dn) |

#### 바로 찍기

- `앞의 키들과 비교해 알맞은 위치에 끼움` → **Insertion**
- `간격 h를 줄여가며` → **Shell**
- `최솟값 찾아 앞에 배치` → **Selection**
- `이웃끼리 교환` → **Bubble**
- `Pivot / Divide & Conquer / Stack` → **Quick**
- `Complete Binary Tree` → **Heap**
- `정렬된 파일 합침` → **Merge**
- `Bucket / Queue / Digit` → **Radix**

#### 복잡도 핵심

- 빠른 평균 → **Quick / Heap / Merge = O(n log n)**
- 최악까지 O(n log n) → **Heap / Merge**
- Quick 최악 → **O(n²)**

## 12. 이분 검색(Binary Search)

키워드:
- **정렬 필수**
- 중간값과 비교
- 검색 범위를 절반씩 줄임

→ **Binary Search**

중간 위치:

`M = (F + L) / 2`

**암기:** `정렬 + 절반`

---

## 13. 해싱(Hashing)

> **Key → Hash Function → Address**

#### 용어

- Bucket → 하나의 주소가 가리키는 구역
- Slot → 레코드 하나 저장 공간
- Collision → **서로 다른 Key가 같은 주소**
- Synonym → 충돌로 같은 Home Address를 갖는 레코드
- Overflow → 해당 Bucket에 **빈 Slot 없음**

---

## 14. 해싱 함수

| 키워드 | 정답 |
|---|---|
| 나머지 이용 | **제산법(Division)** |
| Key 제곱 후 중간 부분 | **제곱법(Mid-Square)** |
| Key를 나눠 더하거나 XOR | **폴딩법(Folding)** |
| 진수 변환 | **기수 변환법(Radix)** |
| 다항식 계수 | **대수적 코딩법** |
| 자릿수 분포 분석 | **숫자 분석법** |
| 난수 발생 | **무작위법(Random)** |

**암기:** `제산·제곱·폴딩·기수·대수·숫자·무작위`

---

## 15. Collision 해결

- **Chaining** → Linked List로 연결
- **Open Addressing** → 다음 빈 주소 탐색
- **Rehashing** → 다른 Hash Function 사용

**암기:**  
`체인 = 연결 리스트`  
`오픈 = 빈 자리`  
`재해싱 = 다른 함수`

## 73. 시간 복잡도

효율 좋은 순:

`O(1) < O(log n) < O(n) < O(n log n) < O(n²) < O(2ⁿ)`

#### 대표

- O(1) → Stack Push/Pop
- O(log n) → Binary Search
- O(n) → 단일 반복
- O(n log n) → Heap / Merge
- O(n²) → 이중 반복 / 삽입·선택·버블 등
- O(2ⁿ) → Fibonacci 계열
